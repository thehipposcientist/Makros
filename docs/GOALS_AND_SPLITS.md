## Target Focus (muscle emphasis)

Users can optionally set a target focus (e.g. "glutes", "chest"). This affects:
1. Weekly set target for that muscle: +30% (capped at advanced tier + 3)
2. Per-exercise set bump: +1 set on exercises hitting that muscle
3. Exercise scoring: +1.5 bonus for exercises reducing the focused muscle's deficit
4. Backfill: isolation accessory appended if deficit ≥ 1 set
5. Split recommendation: biases toward splits with higher frequency for the focused body region

**Focus does NOT change the split structure.** Chosen split = structure. Focus = emphasis within that structure.
